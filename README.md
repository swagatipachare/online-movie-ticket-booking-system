🎬 Online Movie Ticket Booking System

A web-based movie ticket booking application developed using PHP,
MySQL, HTML, CSS, Bootstrap, and JavaScript.

✨ Features

User registration and login

Browse movies and showtimes

Check and select seats

Book movie tickets

Payment/checkout

Ticket confirmation and cancellation

Booking history

Admin dashboard

Manage movies, theatres, screens, shows, users and bookings

🛠️ Tech Stack

Frontend: HTML, CSS, Bootstrap, JavaScript

Backend: PHP

Database: MySQL

🚀 Run Locally

Install XAMPP.

Start Apache and MySQL.

Copy the project into htdocs.

Create a MySQL database and import the .sql file.

Update the database connection in the PHP configuration.

Open:

http://localhost/movie-booking/
